About me

The engineer behind the code

Backend and full-stack engineering, from real-time data pipelines to AI-assisted SaaS and mobile apps.

Who am I?

I'm a software engineer who builds complete products from the database to the screen. My backends are Java and Spring Boot or C# and ASP.NET Core, with TypeScript clients for the web, mobile and desktop, and Python where the data or the models need it. I care about the parts that make software dependable: versioned schema migrations, bounded caches and retention, automatic refunds when a job fails, CI that deploys with a rollback, and an architecture that stays easy to change.
