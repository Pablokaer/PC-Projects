About the project

TechRat is a gamified platform for studying technology and preparing for tech jobs. Learners answer questions, follow roadmaps, earn XP, level up globally and per topic, keep streaks, unlock badges and climb leaderboards. The content runs from programming fundamentals to system design, AI engineering, cloud and DevOps.

The repository holds a working MVP: an ASP.NET Core 10 API, a responsive Next.js web app, an Expo mobile app and a Tauri desktop app, all sharing one API and one set of generated contracts.

Goal

Turn studying for tech jobs into something with momentum: structured roadmaps and a large question bank, each answer explained and linked to official documentation, with gamification that rewards consistency.

What it does

Question bank and roadmaps

2,600+ multiple-choice questions in four difficulties, with explanations and official references, composed into career, language and skill roadmaps from shared modules.

Gamification

XP ledger, global and per-topic levels, streaks, 24 achievements, a daily challenge and global, weekly, monthly and topic leaderboards.

One API, three clients

Web, mobile and desktop hold no business rules. They call the API through types generated from its OpenAPI document.

Consistent by design

Grading, XP, streaks and progress are written in one transaction; achievements and notifications go through a transactional outbox.
